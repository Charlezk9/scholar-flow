### v1.3.0

议程是两列便签板，每张便签分正文与待办两个部分，添加入口常显，多卡可同时展开，复制保留完整内容。议程不显示未来七天事件，仍可主动「安排到某天」。

日视图保留内部月历，原时间轴内容区等分为左侧日常安排、右侧事件。每天默认四个固定虚线块，填写类别后才入库；支持六种建议类别与自定义。同钟点可并排安排。新增独立数据表与 version 4 备份，迁移前完整备份，失败停止升级。

本版实际验证：**473 项测试通过**（纯逻辑与样式 76 + DOM 365 + Rust 32）；72 组浏览器尺寸／字号／密度检查，另有独立测试库的 macOS bundle 交互验证。

### v1.2.0

**新增：议程页 —— 从「时间轴列表」重定义为「待办池」**

- **没有日期的待办**：一个标题 + 若干子项（子项与倒计时里程碑**共用同一套交互**），
  顶栏第三个页面，窄列 720px 居中（待办是「读 + 勾」的场景，不横跨整窗）。
- **「安排到某天」**：与日历的桥 —— 选日期后生成全天事件（未完成的子项写进事件备注），事项移入已完成。
  **单向出口**，因此不存在「删了事件但标记还在」这类双向同步问题。
- 「添加文字／添加待办」入口常显，多卡可展开，正文保存／取消，完整复制；不显示七天事件预览；已完成折叠区；⋯ 菜单六项；置顶用菜单项状态色表达。

**边界钉死（写进术语表）**：倒计时 = 一个不可移动的目标时刻；日历事件 = 一个时间安排；
**议程事项 = 一件要推进但还没决定哪天做的事**。什么时候做已经定了 → 日历，不是议程。

**数据**：新增 `agenda_items` / `agenda_subitems` 两张表（外键 `ON DELETE CASCADE`），
备份升到 `version: 3`；首次升级自动落一份 JSON 兜底。老设置 `defaultView: "agenda"`
在启动时归一到 `month`（议程不再是日历视图）。

### v1.1.0

**字体统一** —— 用 `NSFontManager` 实测发现：宋体**没有 500/600 字重**（原来的中等字重全落回
Regular 或跳 Bold，界面忽粗忽细）、苹方**没有 Bold**（写 700 会被合成假粗）。现统一为
「SF Pro（拉丁/数字）+ 苹方（中文）」一套栈，`-apple-system` 必须排首位（数字才走真实 `tnum`）。

**里程碑（TODO）** —— 倒计时卡片里可加子项：自绘复选框、双击改名、折叠徽章 `☑ 2/5`、
展开动效；删倒计时由外键级联清理子项。

**卡片精简** —— 右上角只留 `⋯`（编辑/皇冠/置顶/颜色全部收进菜单，皇冠与颜色降为只读标记）；
时分秒**内联**到「剩余 N 天」后面，删掉原来那行灰色的「还有」，卡片少一行。

**布局加固** —— 两处实测 bug：迷你月历溢出气泡（`.rail` 写死 180px + `1fr` 的轨道最小值 +
全局 `button` 漏清 UA `padding`）；日历标题过长导致按钮折行、高度抖动（改成「标题让位、操作不让位」）。
周/日视图标题不再显示年份（跨年才补）。

**编辑抽屉** —— 倒计时编辑从卡片里搬到右侧抽屉，两个抽屉的 ✕ 统一在左上角。

### v1.0.0

**新增**

- **皇冠倒计时（`CD-15`）** —— 给最重要那件事一个固定位置：标题栏正下方一整行，
  只放**标题 + 倒计时**，秒级跳动且宽度不抖。全库唯一，四条可见入口
  （卡片按钮 / ⋯ 菜单 / 皇冠栏自身 / 设置页），可在设置里关掉整行。
- **界面字号可调（`UI-13`）** —— 小 / 标准 / 大 / 特大四档（90%–130%），
  设置页即时生效并带局部预览。
- `ContextMenu` 支持按条件隐藏菜单项。

**修复 / 加固**

- **字号放大不再导致页面畸变** —— 这是本版真正的工作量。原来 84 处硬编码
  `font-size: Npx` 和 23 处「承载文字的固定高度」（如 `.btn { height: 36px }`）
  在字号变大后会把文字裁掉、让行错位。现在统一遵守三条不变式：
  ① 每条 `font-size` 乘 `--font-scale`；② 文字容器只用 `min-height`；
  ③ 时间轴行高与滚轮格高由 JS 取整后写回 CSS，保证 CSS 布局与 JS 像素运算同源。
- **月视图按字号自适应行数** —— 大字号下格内最多 2 行（而不是硬裁第 3 行）。
- **滚轮选择器切档不错位** —— 字号变化时按新格高重新对齐到同一个值。
- `db.rs` 抽出一列清单常量与行映射函数，countdowns 的列顺序不再散落六处。
- 12 处内联 `fontSize` 改走 `fs()` helper（内联样式不受 CSS 审计覆盖，最容易漏）。

**数据**

- `countdowns` 新增 `crowned` 列，经幂等 `ensure_column` **自动原地升级老库**，
  有专门的回归测试（手搓一个不含该列的 v0.1 表结构再升级）。
- JSON 备份自动包含皇冠状态，格式未变。**无破坏性变更，可直接回滚旧版。**

**测试**：111 → **207** 项（纯逻辑 35 + DOM 交互 159 + 数据层 13）。
其中 14 条是**样式不变量审计** —— 直接读源码，防止有人把上面三条规矩改回去。

### 被测试抓住的真实事故

1. **时间选择器点了没反应** —— 原本用「透明 + `opacity:0` 的原生 `input[type=time]`」覆盖在胶囊上，
   WKWebView 里点击无任何视觉反馈。现改为自绘双滚轮（时 / 分，吸附 + 高亮带）。
2. **删除功能像没实现** —— 二次确认用了 `window.confirm`，而 Tauri 的 wry 在 macOS 上
   没有实现 `runJavaScriptConfirmPanel`，按 WebKit 规范此时 `confirm()` 不弹窗、直接返回 `false`，
   于是 `if (confirm(...)) doDelete()` 里的删除**一次都没执行过**。现改为站内纸张风格确认弹窗。

3. **抽屉里选不了开始/结束时间** —— `.drawer` 的滑入动画用了 `transform`，且
   `animation-fill-mode: both` 让它在动画结束后**依然保留**。CSS 规范规定非 `none` 的
   `transform` 会让元素成为 `position: fixed` 后代的**包含块**，于是抽屉里的浮层
   不再按视口定位，被推到屏幕外 —— 表现就是「点了没反应」。
   现改为浮层 portal 到 `body`，并把动画 `to` 帧改成 `transform: none`。

4. **字号一调大，文字就被裁掉** —— 22 处「承载文字的固定高度」（如 `.btn { height: 36px }`）
   遇到放大后的文字装不下，第 3 行事件也被月视图格子切掉半行。现改为文字容器一律 `min-height`
   并按字号温和增长、月视图按字号减少格内行数；另加 14 条**样式不变量审计**直接读源码看住。

5. **顺手保存一下，皇冠就没了** —— 「置顶 / 归档 / 复制」都走同一个 `save_countdown`
   整体覆写记录。如果 `crowned` 是带默认值的 `bool`，这些操作会把皇冠静默重置为 `false`。
   现把入参改成 `Option<bool>`：**省略 = 保持原状**，并加回归测试
   `crown_survives_partial_saves`。

6. **回车会顺手把卡片折叠** —— 里程碑输入框里的 `Enter` 冒泡到卡片的 `onKeyDown`
   （`role="button"` 的键盘处理），于是「加一条里程碑」会连带把卡片折起来。
   现改为卡片只处理 `e.target === e.currentTarget` 的按键。

7. **迷你月历溢出气泡** —— 三层叠加：`.rail` 写死 180px（全项目唯一没随字号缩放的尺寸）、
   `repeat(7, 1fr)` 的轨道最小值是「格子的最小内容宽」而不是平均分、以及全局 `button` reset
   **漏清了 WebKit 给的 `padding: 1px 6px`**。三者相加让 7 列总宽超过气泡，格子直接画到外面。
   现改为 `minmax(0, 1fr)` + 清 UA 内边距 + `--rail-w` 随字号变化。

8. **标题一长，按钮就折行、高度乱跳** —— `.cal-title` 有 `white-space: nowrap` 却没有
   `min-width: 0`，于是它的最小宽度 = 整串标题（特大字号下约 600px），**拒绝收缩**，
   右边的「今天 / 跳转 / 视图切换 / 新建事件」只能折成两行。现把「谁让位」写死：
   标题让位（省略号 + `title` 提示完整文字），操作不让位。

9. **改名把备注清空了** —— `saveAgendaItem` 是整条覆写，而改名只传 `{id, title}`，
   于是 `note` 被静默写成 NULL（独立验证的变异测试抓到的）。现新增 `renameAgendaItem`
   单一入口，整体转发 `note / pinned / archived` —— 与第 5 条是同一类教训。

10. **`formatWeekRange` 漏空格** —— 三个分支都渲染成「2026 年 10 月5 日」，
   而同文件的 `formatFullDate` 是「10 月 5 日」。单测抓的。

11. **测试自己会按时钟报假警** —— 皇冠套件用真实时钟算期望值，`已过去 N 天` 按 24 小时取整，
   于是「上午红、下午绿」。现文案断言用固定锚点（当天 18:30），DOM 断言仍用真实时钟。

这些都不是「想一想就能发现」的问题，所以现在有 `pnpm smoke` 真点一遍 + `pnpm test` 里的源码审计；
新功能还会被**独立 subagent** 用变异测试抽查断言是否有效（见 [开发日志](docs/DEVLOG.md)）。

## 功能范围（v1.3）

**倒计时（左栏）**
- 快速创建：标题 + 日期 + 时间（时间留空 = 全天，倒计时到当天结束）→ 点「添加」
- 日期用**自绘月历浮层**：点某天即选定，可翻月、可点「今天」
- 时间用**双滚轮**（时 00–23 / 分 00–59）：拖拽、滚动、点选都行，停止后自动吸附，中间有高亮带；可一键改回「全天」
- **精确到秒，每秒实时跳动**，无需手动刷新
- 显示形态：`剩余 N 天 HH:MM:SS`（同一行，等宽数字）/ 不足一天时直接大字 `HH:MM:SS` / `已过去 N 天 HH:MM:SS`
- 窗口切回前台、休眠唤醒后数字立即纠正，不滞后
- 进度条 + 百分比（设置了起始日期时）
- 置顶、颜色标签、备注、归档
- **皇冠**：给最重要的一条戴皇冠，标题栏下方常驻一整行显示它的标题 + 倒计时（全局唯一）
- **字号**：小 / 标准 / 大 / 特大四档，文字与容器一起长，不裁字不错位
- **里程碑**：卡片内可加子项（TODO），自绘复选框、双击改名、折叠徽章 `☑ 2/5`、展开动效
- 右上角只有 `⋯`：编辑 / 设为皇冠 / 置顶 / 复制一份 / 归档 / 删除（已置顶/已戴皇冠时菜单项带状态色）
- 编辑走右侧抽屉（✕ 在左上角）

**日历（右侧）**
- 月 / 周 / 日三种日历视图；议程为独立页面
- 月视图格内：公历日 + 农历/节气 + 节日 + 事件行（`● 事件名`，最多 2 行 + `+N`）
- 跨日事件以横条跨格渲染，跨周正确截断
- 今日格：便签黄底 + 朱砂描边 + 「今」徽章
- 角标：`休`（法定假）/ `班`（调休）/ `倒`（倒计时目标日）
- 周视图：时间网格 00:00–24:00、全天横条、当前时刻红线

**日视图日常安排（v1.3）**
- 保留内部月历与现有宽度；时间轴左右等分，左日常安排、右事件，共享滚动与刻度
- 每天四个固定空块：08:30–10:00、10:15–12:00、14:30–16:30、19:00–20:30
- 虚框可添加类别：六种建议 + 自定义；按日期保存，清空恢复虚框；允许与右栏事件同钟点

**事件**
- 单日 / 跨日区间、全天 / 定时
- 标题、日期、时间、颜色、地点、备注
- 双击日历格或时间轴空白处直接新建

**议程（v1.3，独立便签页面）**
- 两列便签：一个标题，正文与待办分成两个部分，可共存；待办与倒计时里程碑共用交互
- 顶部常驻快速添加（`Enter` 连续录入）、折叠徽章 `☑ 2/5`、已完成折叠区
- ⋯ 菜单：编辑标题 / 置顶 / **安排到某天…** / 复制一份 / 标记为已完成 / 删除
- 「安排到某天」= 与日历的桥：选日期后生成全天事件（未完成子项写进事件备注），事项移入已完成
- 「添加文字／添加待办」入口常显，多卡可展开，正文保存／取消，完整复制；不显示七天事件预览

**其他**
- 顶栏实时时钟 `HH:MM:SS`，同时写入窗口标题
- 顶栏下方皇冠栏：只放最重要那条倒计时的标题与倒计时（可在设置里关掉）
- 删除 / 破坏性操作走站内纸张风格确认弹窗（不使用原生 `window.confirm`）
- 纸张风格：宣纸底、水墨远山、竹叶、噪点（可一键关闭装饰）
- 设置：周起始日、默认视图、农历/节气/节日/角标开关、密度、主题、字号、皇冠栏
- 数据：JSON 手动备份、数据位置可查看
- 菜单栏常驻：关闭窗口不退出，从菜单栏可新建/回到今天/退出

**指针优先**：所有功能都有可见的鼠标/触控板入口，不要求记忆任何快捷键。
