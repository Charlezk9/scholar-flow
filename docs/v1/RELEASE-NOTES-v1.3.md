# RunningDO v1.3.0 发布说明

> 2026-10-02 · macOS / Apple Silicon · 基线 v1.2.0

议程升级为两列便签板；日历日视图增加独立的日常安排栏。

## 功能

- 议程与日历保持独立页面，议程不再显示未来七天事件；保留「安排到某天」的单向出口。
- 一张便签有正文与待办两个部分，可混合使用。添加文字／待办入口常显；正文支持换行、保存／取消；多卡可同时展开。
- 便签采用暖纸色、分区标签、纸签、柔和阴影与渐入反馈；展开及勾选沿用已有动效，支持系统减弱动态设置。
- 复制便签包含正文及全部待办，保留待办完成状态，生成新 ID，取消置顶与归档。编辑正文使用局部更新，不覆写标题、置顶或归档。
- 日视图保留内部月历与原有宽度，将时间轴内容区等分为「日常安排／事件」两栏，共享刻度与滚动。相同时间可并排安排。
- 每天固定四个空块：08:30–10:00、10:15–12:00、14:30–16:30、19:00–20:30。空块显示虚框及添加入口，块内不强调时段文字。
- 时间块可选英语、实验、开发、文献、写作、课程，也可自定义类别；清空后恢复虚框。类别按日期保存，月／周视图不混入日常块。

## 数据与迁移

新增 `daily_routine_slots`，以 `(date, slot_key)` 唯一标识已填写的块；空块不落库。备份升为 **version 4**，新增 `dailyRoutineSlots`。首次升级先按旧库格式保存完整备份，备份失败即停止新增表；重复启动不重复备份。备份文件名增加小数秒，避免同秒覆盖。

旧议程正文继续使用 `note`。日历事件、倒计时与已有待办无结构性破坏；新旧页面之间不建立持续同步关系。JSON 恢复仍未实现。

## 本次实际修复

- 时间轴原生滚动条占宽导致标题与双栏错位：现在随窗口变化同步预留宽度。
- 日视图多个全天事件在同一行覆盖：每条各占一行，跨日事件也保留入口。
- 滚动后双击新建事件重复加上滚动偏移：使用视口坐标与网格边界的差值；结束时间正确增加一小时并限制在当天内。
- 窄窗、大字号下顶栏入口被挤出：搜索与日期文字先收缩，三个页面入口保持可见。
- 正文、类别、待办添加失败保留草稿并提示；安排弹层防重复提交，Esc／取消／遮罩行为明确；两种弹层限制键盘焦点并关闭后归还焦点。

## 限制

四个时段不可改、不可拖拽、不可增删；每块一个类别，不做提醒或统计。正文仅纯文本，最多 5000 字符；类别最多 20 字符。窄窗长文字可能换行或截断，可通过提示／展开读取完整内容。原生交互验证使用本机系统，未在实际 macOS 11 设备上执行。
