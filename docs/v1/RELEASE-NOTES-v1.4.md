## v1.4.2 · 文献阅读、资料库与中文翻译

文献页采用资料库与主阅读器布局。顶部集中创建操作，左栏为可折叠目录树和紧凑文献行；长标题省略，父目录累计所有层级的文献数量。目录选择与箭头折叠分离，文献/文件夹右键支持对应的创建、阅读、重命名、移动和删除；移动卡展示层级树，禁止目录移入自身或后代。定位当前文献会展开祖先、滚动并高亮，重新进入恢复选中项、折叠及左栏滚动位置。

PDF 上下连续滚动，按需渲染相邻页；标题栏集中页码与10%步长缩放，以及MD的12–28px阅读字号。修正KaTeX公式上下标、分数、根号及定位样式；MD支持受控本地配图及正文、图注、脚注、作者信息的差异排版。每次转换（含Office）自动调用模型检查结构并整理，原始数据仅内部保存，界面提供最终Markdown入口。处理中显示状态，失败可以重试。

文献详情以浮层平移展开，不压缩阅读器宽度，分为元数据、附件、建议元数据。一个文献条目只允许一个PDF源；已有源隐藏导入，提供清空确认。附件以文件名和图标操作对齐，MD可独立删除或重新生成；读取失败显示具体提示。附件入口使用macOS原生文件选择窗口，无需输入路径。

整理后的MD可生成中文学术译稿，按信达雅约束事实、逻辑、术语和限定条件，原样保护数值、公式、代码及图片引用。翻译按钮位于文献详情的转换选项下方；原稿、中文可单独阅读或横向双栏对照，每组对应段首由共用网格行自动对齐。翻译采用低思考强度、流式小批次请求，显示已完成段落和重试状态；失败保存已校验批次，继续翻译时复用检查点，最终稿仅在全部段落通过校验后开放。

### 验证

最终检查：76逻辑/样式 + 497 DOM + 48 Rust + 15 Python，共636项通过；macOS debug app构建成功。

真实15页论文自动整理：159区块、5张配图，约41秒，逐区块核对无遗漏；调用估算¥0.042，非账单。该论文150段整理稿完整中文翻译约211秒，校验通过；完整检查点重用约0.172秒，译稿哈希不变。整篇翻译在隔离目录验证，未覆盖已有文献库。详情展开前后阅读区宽度保持不变；1040px、大字号及28px阅读字号下对照段首偏差为0，无横向溢出。

原生已验证PDF、公式、配图、自动整理及Finder风格附件窗口；资料库拖放配置及前端事件链已修正，但原生鼠标拖动验收被工具`noWindowsAvailable`阻断，仍需实机确认。未验证macOS 11实机。

## v1.4.0 · 文献模块基础

新增文献页、层级文件夹、论文/教材/杂志等类型、全库唯一标题、阅读状态与跨文件夹标签。附件拷贝入数据目录并以sha256幂等去重；PDF.js本地worker渲染canvas与文字层，PDF提供缩放，Office阅读通过markitdown转换稿呈现。

建立本地快线与GLM云端提取，产物和源附件同目录持久保存，同文件同引擎复用缓存。云引擎返回标题、作者、年份、期刊/会议等建议元数据，用户可主动采纳；首次云提取提示上传内容和费用，密钥仅后端读取，云提取失败可降级本地。

当时验证：76逻辑/样式 + 422 DOM + 46 Rust，共544项通过；真实PDF本地提取、浏览器与原生阅读、DOCX/PPTX转换及1040×700大字号核验。真实GLM单页约11.912秒、2735字符，调用估算¥0.0059308；该样本仅覆盖标题和摘要，不代表全文质量验证。历史证据见[计划A章](PLAN-v1.4.md#initial)。

## 数据与运行边界

JSON备份version 5包含文献元数据、标签及关联，**不包含PDF、MD、配图、翻译映射及检查点**；迁移时需另行拷贝数据目录的`files/papers/`。JSON导入恢复仍未实现。

云提取、整理和翻译需要现有云服务配置，并产生API费用；模型对其他论文版式与译文质量仍需人工核对。原始Office附件通过转换后的MD阅读。文献相关需求的完整状态及未完成范围只在PRD §5.0维护。
