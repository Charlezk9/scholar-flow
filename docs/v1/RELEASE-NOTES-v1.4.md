# RunningDO v1.4.0 发布说明

> 2026-10-04 · macOS / Apple Silicon · 基线 v1.3.0

新增「文献」页，以文件夹树、条目列表、详情三栏管理论文、书籍与资料。

## 本次变化

- 文件夹管理、全库唯一且可直接编辑的标题、阅读状态、跨文件夹标签；附件拷贝入数据目录并以 sha256 幂等去重。
- PDF.js 本地 worker 渲染 canvas 与文字层，支持换页、缩放；失败时可手动使用系统预览。
- PDF 本地快线与 GLM 云端提取；DOCX/PPTX 使用 markitdown。提取稿与附件同目录持久保存，同文件同引擎复用缓存；Markdown 支持标题、表格及 KaTeX 公式。
- 云端返回建议标题、作者、年份与期刊/会议，可主动采纳。首次云提取提示上传页面和费用；密钥仅在后端读取，云失败可降级本地。
- 备份升为 version 5，包含文献元数据、标签和关联。JSON **不包含附件与提取稿**，请另行备份数据目录中的 `files/papers/`；JSON 导入恢复仍未实现。

## 验证与实际限制

`pnpm check`：76 单元/样式 + 403 DOM；`cargo test`：46 项，共 525 项通过。真实 15 页论文通过本地提取及浏览器/原生 PDF 阅读；原生换页和文字层通过。DOCX/PPTX 转换实跑通过。1040×700 大字号布局检查通过。

真实 GLM 单页：11.912 秒、2,735 字符，4,981 输入 / 695 输出 tokens，按公开中国区单价估算 ¥0.0059308，非实际账单。标题与摘要可用；公式、表格、参考文献及全文云提取质量尚未由该样本验证。详细证据见 [PLAN §2.4](PLAN-v1.4.md)。

当前云管线逐页串行；全文并发、断点续提及 PRD 中其余部分完成项未宣称完成。阅读原始 Office 文件通过转换稿呈现。原生验收使用隔离数据目录；未进行 macOS 11 实机验证。需求与完成状态以 [PRD §5.0](../v0/PRD.md) 为准。
