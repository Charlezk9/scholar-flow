## 1. 设计方向定调

| 维度 | 结论 |
| --- | --- |
| 主题 | Pristine Light Mode —— 宣纸底 + 水墨点缀，**全应用无深色模式** |
| 背景 | 暖白纸面 + 极轻噪点；窗外有水墨山水留白 |
| 字体 | **SF Pro（拉丁/数字）+ 苹方（中文）统一字体栈**（v1.1 `UI-18` 决议，详见 §3） |
| 主强调 | 朱砂红 `#A2362C`，只用在：主按钮、剩余天数、今日、"今"徽章、节日名 |
| 层级手段 | 靠**字重 + 字号 + 颜色深浅**，不靠边框和阴影堆叠 |
| 圆角 | 克制：`4 / 6 / 8px` 三档，无胶囊、无大圆角 |
| 阴影 | 极轻：`0 1px 3px rgba(90,70,50,.08)`，仅用于浮起纸片 |
| 装饰 | 水墨插画 / 竹叶 / 梅花 / 纸张纹理 —— **全部走"纸张装饰"总开关** |

## 3. 字体与字号层级

> **v1.1（`UI-18`）改版说明**：本节原先规定「标题 / 数字 / 日号用宋体，正文用无衬线」，
> 并把「衬线混排」当作最强识别特征。实测发现宋体在 macOS 上只有
> `Light / Regular / Bold / Black` 四档 —— **没有 500/600**，于是 `font-weight: 500` 全部落回
> Regular、`600` 直接跳到 Bold，中间层次全丢，看起来忽粗忽细；`--font-num` 还把数字
> 交给 Times New Roman，与中文宋体不是一套设计。
> 现统一为「**SF Pro（拉丁 + 数字）+ 苹方（中文）**」：字重层次真实可用、数字可用
> `tabular-nums` 真实等宽、跨设备回退稳定。新的识别特征是
> **等宽数字 + 600/500/400 三级字重对比 + 纸张质感**，不再依赖衬线。

| --- | --- | --- | --- | --- |
| 应用名 | SF Pro / 苹方 | 20 / 28 | 600 | `--ink-1` |
| 倒计时天数数字 | SF Pro / 苹方 | **34 / 38** | 600 | `--cinnabar` |
| 倒计时"剩余"前缀 | SF Pro / 苹方 | 15 / 20 | 400 | `--cinnabar` |

**字体栈**

```css
/* v1.1（UI-18）：三个 token 值相同、语义不同，便于后续只调字重/字距而不换栈。
   顺序不可反：-apple-system 必须排第一，数字才走 SF Pro 的真实 tnum。 */
--font-ui:      -apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Helvetica Neue", Arial, sans-serif;
--font-display: 同上（标题 / 大数字）;
--font-num:     同上（会跳秒/跳数的位置，必须配 font-variant-numeric: tabular-nums）;
--font-serif:   var(--font-ui);   /* 过渡别名，v1.2 删除 */
```

**必须遵守**

1. **不许写 `font-weight: 700`**：PingFang SC 没有 Bold，WebKit 会合成假粗（笔画发糊）。需要「重」用 `600`，「中」用 `500`（两者在苹方里都是真实字重）。
2. **会跳秒/跳数的元素必须声明 `font-variant-numeric: tabular-nums`**：顶栏时钟、卡片大字、时钟行、皇冠栏时间、滚轮数字、字号预览。
3. **不许在 `app.css` 里写裸 `font-family`**：一律走 `--font-*` token（有样式不变量审计看住）。
4. 换字体后中英文行高会变：新增文本要按上表重新核对行高，不要照搬旧值。

> 采样说明：原参考图的衬线调性由此让步于一致性与可读性，纸张质感改由
> 底色 / 噪点 / 水墨装饰 / 朱砂强调承担（参见 §2 与 §6）。

## 5. 组件规格

### 5.1 顶栏（图 1）

```
[● ● ●]  RunningDO   ☀ 2026 年 6 月 1 日 星期一                    [日历] [议程] [文献] [设置]
  78px     衬线20      淡墨 · 无衬线13.5 · 居中偏左                        右对齐 · 页面入口
```

- 高度 `52px`，底色 `--paper-panel-alt`，底部 `1px --line`。
- 左 `78px` 为红绿灯安全区，`data-tauri-drag-region` 覆盖整条非交互区。
- 页面入口：日历 / 议程 / 文献（v1.4）/ 设置。**v1.4 起移除原「搜索」占位按钮**（其需求 `CD-13` / `EV-11` 已作废，见 PRD §5.0 作废编号）。

### 5.1b 皇冠栏（`CD-15`，标题栏下方一整行）

```
▎         👑  期末考试   剩余 12 天 05:32:11                     ⊙
 3px      SF Pro/苹方 15/500 · --ink-1 · 超长省略   等宽数字 15 · --cinnabar-deep   取消按钮绝对定位右端
```

- **位置**：顶栏（`5.1`）正下方，贯穿整个窗口宽度，在 `.body` 之上；纵向弹性项，`flex: 0 0 auto`。
- **对齐（v1.1 `UI-14`）**：图标 + 标题 + 倒计时包一层 `.crown-main`，**整体水平居中**（`.crown-bar { justify-content: center }`）。
  倒计时**不得**再用 `margin-left: auto`（那是旧的两端对齐）；「取消皇冠」按钮 `position: absolute; right: 12px`，
  脱离文档流 —— 若留在流里，它自身的宽度会把内容组推偏。标题 `max-width: min(34%, 320px)`。
- **高度**：`var(--crown-h)`，基准 `38px`，随字号增长。必须用 `min-height`，不能用固定 `height`。
- **只放两样东西**：标题 + 倒计时。**不放**日期、进度条、备注、颜色点。
- 左侧 `3px` 朱砂竖线（`::before`，`opacity .5`）当书签；`.is-today` 时底色转 `--cinnabar-tint`；`.is-past` 时整行 `opacity .6`、时间转 `--ink-3`。
- 文案：`剩余 N 天 HH:MM:SS` / 不足一天时去掉「N 天」/ 过期 `已过去 N 天 …`。
  时间用 `font-variant-numeric: tabular-nums` + `white-space: nowrap`，**秒在跳但宽度不抖**。
- **显隐**：没设皇冠、皇冠那条被归档、或 `SET-12` 关掉时，整行不渲染（不留空白占位）。
- **入口（全部可见，不靠快捷键）**：
  1. 卡片 `.cd-actions` 里的皇冠按钮（戴冠时加 `.crown-on` 高亮）
  2. 卡片右键 / ⋯ 菜单的「设为皇冠 / 取消皇冠」
  3. 皇冠栏右侧的取消按钮 + 点标题直接编辑
  4. 设置 → 显示 → 皇冠栏（开关 + 当前皇冠 + 取消按钮）
- **唯一性**：全库只能一个。`set_crown` 在一个事务里先清后设；`save_countdown` 带上
  `crowned` 时也会自动互斥。入参 `crowned` 省略（`None`）＝ 不改动，
  这样在卡片上点「置顶」或「归档」不会顺手把皇冠弄丢。

### 5.2 左栏 · 创建区（图 1/图 2）

- 面板：`--paper-panel`，`--r-lg`，`--shadow-paper`，内边距 `16px`。
- 标题行：朱砂圆角方块 `24×24` + 白色 `+`（`--r-sm`）+ "新建倒计时"（衬线 17/600）。

### 5.3 左栏 · 倒计时卡片（图 2 是关键依据）

> **v1.1 改版（`UI-23` / `UI-24`）**：① 右上角的常驻动作（编辑 / 皇冠 / 置顶 / 颜色）
> 全部收进「⋯」菜单，卡片右上角**只剩 ⋯ 一个入口**；② 时分秒**接在「剩余 N 天」同一行**，
> 删掉原来那行灰色的「还有」，卡片少一行、视线不再被拆成两段。

```
┌──────────────────────────────────────────┐
│  剩余  12  天  05:23:41                  ⋯ │   ← 剩余/天(15/34) · 时钟内联(--font-num 15/600)
│  期末考试                                 │   ← 400/600 视字重档位
│  📅 2026-06-07 周日 · 09:30  👑  ●  ☑ 2/5 │   ← 无衬线 12.5 / ink-3
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░   83%          │   ← 进度条 3px + 右侧百分比
└──────────────────────────────────────────┘
```

**满/缺信息行（`UI-24`）**

| 情形 | 信息行 | 说明 |
| --- | --- | --- |
| 天级 + 有具体时间 | `剩余 12 天 05:23:41` | 时分秒内联，等宽数字，`--cinnabar-deep`，`margin-left: 6px` |
| 天级 + 全天 | `剩余 12 天` | 全天语义下秒跳动没有意义，不显示时钟 |
| 不足一天 | `剩余 05:23:41`（主视觉） | `.cd-days.is-clock` + `.clock-num`（26px） |
| 全天 · 今日 | `就是今天` | 淡黄便签底 |
| 已过期 | `已过去 3 天 02:11:05` | 时钟转 `--ink-3` |

| 属性 | 规格 |
| --- | --- |
| 字体 | `.cd-days .clock-inline`：`--font-num` + `tabular-nums` + `font-feature-settings: "tnum" 1` |
| 字号 | `15px × --font-scale`，与 34px 的天数形成层级但不掉到看不见 |
| 对齐 | `.cd-days` 是 `align-items: baseline` 的 flex，时钟与天数**共用基线** |
| 宽度 | 全部 `padStart(2)` + `tabular-nums`，**每秒变化时宽度零抖动** |
| 已移除 | 旧的 `.cd-clock` 胶囊行与灰色前缀「还有」（`UI-24` 明确删除） |

> **动效克制**：秒位不做 pulse 动画 —— CSS 动画周期无法与真实秒边界对齐，会看起来「走得不准」。只靠数字变化表达活力。

### 5.11 浮层定位（必须遵守）

**规则一：所有 `position: fixed` 浮层必须 portal 到 `document.body`**

涉及：选择器浮层 `pop`、右键菜单 `menu`、月历日弹层 `day-pop`、确认弹窗 `confirm` + `mask`。
统一走 `src/components/Portal.tsx`。

**规则二：祖先动画不得残留 `transform`**

CSS 规范：任何非 `none` 的 `transform` / `filter` / `will-change` 都会让元素成为
`position: fixed` 后代的**包含块**。此时 `getBoundingClientRect()` 拿到的视口坐标
被当成祖先内坐标，浮层会被推到屏幕外。

```css
/* ✗ 错误：动画结束后 transform 仍为 translateX(0)（fill-mode: both） */
@keyframes slide-in { from { transform: translateX(100%) } to { transform: translateX(0) } }

/* ✓ 正确：结束后回到 none，不再充当包含块 */
@keyframes slide-in { from { transform: translateX(100%) } to { transform: none } }
```

| 浮层 | 曾经的坑 | 现在的保障 |
| --- | --- | --- |
| 选择器 `pop` | 抽屉里点时间无反应（被 `.drawer` 的 transform 劫持） | portal + `to { transform: none }` |
| 右键菜单 `menu` | 在左栏内定位，暂无 transform 祖先 | portal |
| 日弹层 `day-pop` | 同上 | portal |
| 确认弹窗 `confirm` | 同上 | portal |

回归测试：`src/__smoke__/drawer.smoke.tsx` 断言「浮层不在 `.drawer` 子树里」且
「`slide-in` 的 `to` 帧是 `transform: none`」。

### 5.15 文献页与阅读层（v1.4）

顶栏增加「文献」，与日历／议程／设置平行。采用类似 VS Code 的工作台结构：左侧资料库内包含文件夹、文献列表及「新建文献项目」入口；点击入口在左栏展开录入表单，标题明确标注必填，空标题点击添加会提示并聚焦输入框。主区域合并为阅读器，标题让位、PDF/MD 与详情按钮保持可达。左侧采用资源管理器：顶部图标集中新建文献、文件夹及删除选中文件夹；表单按需展开。文件夹用箭头展开/收起，文献以文件图标和缩进的单行标题呈现，长标题省略并通过悬停显示完整内容；年份、来源及阅读状态移到详情。行内图标不收缩、标题让位，折叠不打断当前阅读。

文献详情默认隐藏，标题栏右侧不同颜色的 < / > 控制平移唤出和关闭；详情 Portal 到 body，定位覆盖阅读器右侧，不参与正文分栏，展开前后阅读宽度不变。详情分元数据（含标签及状态）、附件、建议元数据三部分；按钮按需换行，详情独立滚动。

选中文献自动读取 PDF；MD 无成功提取稿时灰显，完成提取后启用，切换只改变阅读内容。生成 Markdown 入口位于详情的附件区，处理中使用不定量进度条，成功后收起完整进度条，失败显示重试提示；接口尚未报告逐页百分比，不展示估算百分比。切换文献取消迟到读取的显示更新。

类别、阅读状态与标签使用自绘纸签按钮；选中态为朱砂边线、淡黄纸底。附件按文件名紧凑展示，点击名称阅读，删除和重生成用图标表示；长文件名省略并有完整提示。导入入口为「选择附件…」按钮，打开 macOS 原生文件选择窗口；选好后直接导入，无路径输入框，取消不新增记录也不提示成功。标签与文件夹正交，按名复用，按钮切换当前文献的关联，不删除标签本体。删除文献与文件夹走站内确认。

PDF 阅读器使用本地 PDF.js worker、canvas 与可选中文字层，多页按原文顺序纵向排列，滚动更新当前页码，工具条提供页码与缩放；取消上一页／下一页按钮。横向放大内容只在阅读器内部滚动；加载／失败提示可见，失败页有明确提示。切换文献时销毁阅读任务，迟到响应不能盖住新文献。

Markdown 以语义标题、段落、列表和表格呈现，KaTeX 本地渲染行内／独立公式；原始 HTML 跳过，配图以登记的本地 PNG 资产读取字节后生成 Blob URL；外部图片不发请求，缺失有提示。docx/pptx 经 markitdown 生成同目录同主干提取稿再阅读。建议元数据明确使用「建议／采纳」，不自动覆盖文献字段。

v1.4.2 阅读工具栏合并标题、PDF/MD、当前模式操作与详情入口。标题主动收缩，按钮不收缩；极窄窗口允许有序换行。PDF 的页码/缩放与 MD 字号均位于标题栏，按钮缩小，PDF 每次调整 10%，MD 模式隐藏提取重复状态。

MD 独立字号默认 16px，12–28px、每步 2px，支持减小/增大/恢复默认，阅读会话内保留。正文、标题、图注、脚注均以该字号为基数叠加全局字号。`:::caption`、`:::metadata`、`:::note` 分别呈现图注、作者机构及脚注/说明，字号为正文的 85%；普通 `>` 保持原文引用含义。数学断词独立；KaTeX 样式与渲染版本统一到 0.16.47，并保留生成的内联定位参数。单行双美元公式转换为独立数学块，长公式在自身区域横向滚动。

提取成功后自动进入云整理阶段（沿用 GLM 授权与密钥），模型只分类原文区块及核对配图区域，程序保留原文、公式与来源页码，另存 `<主干>.layout.md` 与 `<主干>.layout.assets/`。每次转换（含 Office）后自动排版；原稿仅内部保存。阅读器和详情只呈现一个最终 Markdown，不列出 glm/layout 或原稿查看入口。整理失败或缺少配置提示重试，已有完成稿仍可阅读。图片区由原 PDF 渲染裁切，使用 PDF 文字框补全边缘标签。

连续 PDF 仅读取全篇页尺寸，画布与文字层按可视页及相邻区域加载；离屏页保持准确尺寸、释放画布，切换文献与迟到任务取消，缩放/换宽按比例保留滚动位置。

设置页的数据说明：JSON 备份包含文献及标签元数据，**不含附件与提取稿**；迁移时另行拷贝 `files/papers` 目录。提取稿与原附件同目录共同搬迁。

## 10. 实现优先级建议

按"看得见的还原度"排序，v0.1 依次攻下：

1. **色板 + 字体 + 圆角 + 阴影** 落地到 CSS 变量（半小时，但决定整体气质）
2. **顶栏**（含红绿灯安全区与拖拽）—— 第一眼就是 macOS 原生感
3. **左栏倒计时卡**（三态 + 进度条）—— 参考图最精细的组件
4. **月视图网格**（日号 + 农历 + 事件行 + 角标 + 今日格）—— 信息密度最高
5. **事件编辑抽屉** —— 表单与按钮组合
6. **周视图**（时间网格 + 全天横条 + 事件块）—— 交互最复杂
7. **设置页** —— 结构固定，最后做

文献阅读实现注意：WKWebView 缺少 ReadableStream 异步迭代时，PDF.js TextLayer 直接接收 `streamTextContent()`，由自身 `getReader()` 消费；避免调用依赖异步迭代的 `getTextContent()`。

资料库文献行可拖放到文件夹或未分类，目标以朱砂虚线与浅底高亮，拖动光标明确；文件夹右键菜单 Portal 到 body，支持新建子文件夹。底部提供简短操作提示。每条文献只能有一个 PDF 源，已有源隐藏导入入口，提供清空源及明确确认；最终 MD 作为附件可读/可删除，删除 MD 不删除 PDF 源或内部原稿，清空 PDF 源沿用同主干资产生命周期清理。转换选项默认折叠。

附件按文件名行排列，PDF 与 MD 名称列、×删除列共用网格，MD 另有重生成图标；点击文件名阅读，长名省略并提供完整名称提示。文献右键“移动到目录”打开居中小卡片，展示可折叠的层级目录树及完整路径提示，选定后移动；拖放悬停展开折叠目录，支持内部拖动引用与文本类型后备。

详情面板统一采用分区16px、字段10px、区内8px间距；状态与字段保持间隔，空导入/标签行不参与布局。附件图标操作列随全局字号调整，删除仅为 ×，名称主动省略；标签输入与添加按钮保持同排。PDF/MD 文件读取失败直接在正文显示失败提示，不残留加载文案。

资料库目录箭头只控制展开/折叠，名称只选择目录。右键菜单作用于点击对象：目录提供新建文献、子目录、重命名、移动、删除；文献提供阅读、重命名、移动、删除。目录移动禁用自身及后代。顶部定位按钮展开当前文献祖先、滚动到条目并短暂高亮，保留无关折叠；左栏选中目录、文献、折叠和滚动位置在重新进入时恢复，失效对象安全回退。

目录名称后的计数为该目录及所有层级子目录内文献总数，折叠不影响计数；未分类只统计无目录文献。移动文献后各层祖先计数同步刷新。

文献详情的转换选项下方放置翻译入口，标题栏提供中文/对照视图切换。译稿由整理后的MD生成，原稿MD入口保持独立阅读；译文未完成时禁用中文与对照。连接时显示不定量状态，随后显示已完成/总段落进度及当前批次重试状态；失败显示具体原因，保留已校验批次供续译。对照为等宽双栏、共用纵向滚动，每组对应段落占同一网格行，以较长内容撑开行高；不固定段落高度，字号/窗口/图片变化后自动保持段首对齐。图注/脚注/作者信息沿用原稿的语义样式，公式与图片引用不翻译；译稿独立阅读隐藏注释标记。

### 文献错误反馈（v1.4.2）

文献转换或翻译失败时，页面保留可操作的错误提示，并提供“查看诊断”。诊断浮层通过 Portal 展示错误码、阶段、操作编号、失败段落及规则，支持复制脱敏信息和打开本地日志目录；浮层不改变阅读器宽度。
