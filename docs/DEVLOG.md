## 2026-10-02 · 一天之内从 v1.0.0 推到 v1.2.0

起点：v1.0.0 已发布（皇冠栏 + 字号可调）。这一天做了 5 轮：修假红测试 → v1.1 五个目标 → v1.2 议程重定义 → 独立验证两轮 → 验证通道修复。

### 第 1 轮 · 接手：先把仓库跑绿

**动作**：`pnpm check` 一跑就红了一条 —— 皇冠套件的「已过去显示『已过去 N 天 …』」。

**根因**：断言用真实时钟算期望值，而 `iso(-3) 12:00` 在**中午之前**只差 2 天 22 小时，`已过去 N 天` 按 24 小时取整得到 2 → **上午红、下午绿**（v1.0 发布时是晚上跑的，所以没暴露）。

**修法**：文案断言改用「当天 18:30」这个固定锚点；DOM 断言仍用真实时钟（`iso()` 要相对今天生成日期）。

**教训**：与时间有关的断言必须固定「现在」，否则测试会按时钟报假警。

### 第 5 轮 · 验证通道本身也是要修的

第一轮被迫用**前台**模式，因为后台起不来。一路查下来：

| 现象 | 根因 |
| --- | --- |
| `neither is available` | `~/.pi/agent/npm` 缺 `@earendil-works/pi-coding-agent`（pi-subagents 的 peer 依赖） |
| `async runner did not produce a pid` | 后台 runner 是**独立进程**，`resolveNodeExecutable()` 在 Electron 宿主下会退回裸命令 `"node"`；而 Dock 启动的 GUI 应用 PATH 只有 `/usr/bin:/bin:/usr/sbin:/sbin`，且那四个目录受 SIP 保护写不进去 |

试过并证明**不够**的：`~/.local/bin/node` shim、`launchctl setenv PATH`、LaunchAgent、重启 Dock —— 13:10:33 与 13:13:36 两次从 Dock 启动的 pi-gui 仍是旧 PATH（Dock/LaunchServices 不把会话 env 传给新 App）。

最终解法：给 pi-subagents 打**两处本地补丁** —— `resolveNodeExecutable()` 增加 `PI_SUBAGENT_NODE_BIN` → `~/.local/bin/node` 两级回退；runner 的 env 前置常用工具目录到 PATH（否则后台子会话的 `node`/`pnpm`/`cargo` 都找不到）。补丁与回退写在 `~/.pi/agent/npm/PATCHES.md`（改动旁保留 `.orig`）。

修完后台自检通过，第二轮验证就是真在后台跑的。

## 这一天固化下来的工程习惯

1. **「谁让位」必须写死** —— flex/grid 里不声明谁收缩，就会一起变形（标题栏按钮折行、迷你月历溢出气泡都是这一条）。
2. **整条覆写的接口必须区分「省略 = 保持原状」** —— `crowned: Option<bool>`、`sortOrder: Option<i64>`、`renameAgendaItem` 整体转发字段，都是同一个教训的三次复现。
3. **动效有两个 macOS 11 基线上的禁区** —— 不用 `grid-template-rows` 过渡（Safari 14 不支持）、不让动画留下 `transform`（会成为 `fixed` 后代的包含块）。降级只用媒体查询，**不用容器查询**（Safari 16 起才有）。
4. **样式与结构约束写成断言，读源码审计** —— 「文字容器只用 `min-height`」「禁止原生 checkbox」「禁止 `@container`」「`.cd-clock` 不得复活」这类规矩，靠注释会被后人（包括我自己）改回去，靠测试不会。
5. **原生控件零容忍** —— 原生 `date/time` 覆盖层、原生 `checkbox`、原生 `select`、`window.confirm/prompt` 在 WKWebView 里要么没视觉反馈、要么样式割裂、要么静默失败（wry 没实现 JS 对话框）。
6. **先取证再动手** —— 目标先落成带「现状证据（文件:行）+ 验收标准 + 待拍板项」的施工图；改完的结论都要能指回具体命令输出。
7. **独立验证要用变异测试自证有效** —— 「测试全绿」不等于「测试有效」；把实现改坏看断言是否真红，才知道有没有假绿。
